## Открытые вопросы — решены 2026-10-08 (заказчик: «выбери сам лучший вариант»)

`evaluation.py:680`, чтобы коллаб не считался «нет модели». Текст вопросов оставлен ниже для истории.

- **В1. Одна группа описания на фразу или на класс?** Реконструкция плана пишет slug
  `_desc-<class>`: одна группа на класс в типе, например «Посадка · брюки». `docs/GROUPING.md` §0
  приводит пример «Baggy · брюки», то есть группу на фразу. Метрики eval выбор не затрагивает, они
  смотрят только `kind` (`evaluation.py:448–451`). «Тренды» затрагивает: группа на класс смешает
  Baggy, Wide Leg и Flared. **Рекомендация:** группа на фразу, slug `_desc-<фраза>` (`_desc-baggy`);
  класс берётся из словаря описаний и в базе не хранится.
- **В2. Порядок назначения.** Он следует из решений 1 и 3: модель → коллаб-линейка → описание →
  «Без модели». Иначе «Yeezy Gap Wide Leg Sweatpants» уйдёт в описание «Wide Leg». Но eval считает
  описание «нет модели» и для коллабов (`evaluation.py:680`), и тогда цель «Yeezy Gap ≤ 5%» не
  пройти. **Рекомендация:** принять этот порядок.
