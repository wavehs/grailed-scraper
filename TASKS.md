# План Grailed Liquidity Analyzer

Цель продукта — находить вещи, которые сейчас становятся ликвидными: растут продажи,
вещи быстро уходят по хорошей цене, а предложение ещё небольшое. Данные — только
живой Grailed через публичный поисковый ключ Algolia, обычным HTTP.

Фазы 0–5 прошлого плана (доступ к Grailed, live-only, полный сбор бренда, lifecycle,
runtime/UI, устойчивость) закрыты; обезличенные отчёты лежат в `data/logs/archive/`.

## Обязательные правила

- Только live Grailed, только read-only публичные данные; соблюдать ToS и `robots.txt`.
- Не больше 90 запросов/мин и 3 одновременных запросов; при CAPTCHA или повторяющихся
  429 прогон останавливается.
- Не логировать и не возвращать ключи, соль и PII продавцов. Деньги — `Decimal`.
- Неполная выборка всегда видна как `partial`/`truncated`.
