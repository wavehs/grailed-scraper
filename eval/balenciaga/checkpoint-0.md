## Находки для v7a и v7b

1. **Неверная линейка (класс 4) видна в эталоне.** Строгое сопоставление в 20 строках
   верно, а по линейке — нет: правильная группа лежит под обрывком. Mud Show ← Mud,
   Speed Hunters ← Speed, 3B Sports Icon ← Sports, Garde Robe ← Robe, Trompe L'oeil ←
   Trompe, Gym Wear ← Wear, Dove No Seam ← No Seam. Правило префикса из п. 4.4 исправит
   Robe, Sports, Wear и No Seam. Mud, Speed и Trompe — настоящие префиксы, их исправят
   только seed-ы (Mud Show, Speedhunters, Trompe L'Oeil). Нужно проверить на v7b: родителем
   не должна становиться линейка, которая сама — обрывок.
2. **«No Seam» — не только Dove.** Есть Logo No Seam Tee Yeezy Gap без Dove. Обрывок нельзя
   склеивать с Dove по умолчанию.
3. **Классы эталона.** Из 1 375 непограничных строк 664 — модели, 549 — `DESCRIPTOR`,
   162 — `NONE`. Строки `DESCRIPTOR`, оказавшись в описательных группах, перестанут снижать
   точность модели в варианте D.
